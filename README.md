# Проект "Рабочее место менеджера ателье по ремонту бытовой техники"

___Сайт разработан на фреймворке Angular с базой данных Supabase___

## Возможности сайта
**Аккаунты:**
* Регистрация пользователя
* Авторизация пользователя
* Выход из аккаунта

**Работа с таблицами БД:**
* Просмотр таблиц
* Изменение записей в таблице
* Удаление записей
* Сортирока таблицы
* Фильтрация данных в таблице
* Выбор и просмотр представлений таблиц
* Экспорт записей таблицы в формате CSV

**Дополнительно:**
* Справка по использванию сайта
* Домашняя страница со статистикой
* Окно с профилей текущего пользователя

Достаточно перейти по ссылке: https://youzik-prog.github.io/Repair-service/


## Локальный запуск проекта

Для начала нужно скачать ZIP-архив проекта, либо использовать комманду в терминале:
```Bash
git clone https://github.com/Youzik-prog/Repair-service
```
После чего нужно в терминале перейти в директорию с этим проектом и запустить с помощью команды:
```Bash
ng serve
```
⚠️Важно подметить, что для корректной работы проекта нужен Angular 21!

При успешнй сборке проекта нужно в поисковую строку браузера ввести http://localhost:4200 и проект запустится
